# Projet C

Bienvenue dans notre dépôt d'équipe ! Nous n'avons pas encore choisi le projet : cette base servira à apprendre à travailler ensemble et à tester du code en C.

## Pour commencer

1. Installez un compilateur C, par exemple GCC.
2. Clonez le dépôt sur votre ordinateur avec GitHub Desktop, ou avec la commande :

   ```bash
   git clone https://github.com/Killian-Lett/projet-c.git
   ```

3. Ouvrez le dossier du projet dans votre éditeur de code.
4. Modifiez `main.c`, puis compilez et lancez le programme avec les commandes ci-dessous.

## Compiler et lancer

Depuis le dossier du projet, dans un terminal :

```bash
gcc -Wall -Wextra -std=c11 main.c -o projet
./projet
```

Sur Windows, lancez le programme compilé avec :

```powershell
.\projet.exe
```

## Fichiers

- `main.c` : point de départ du programme.
- `.gitignore` : fichiers générés ou propres à votre ordinateur que Git n'a pas besoin d'enregistrer.

## Travailler à plusieurs

Pour l'instant, vous pouvez chacun proposer de petites améliorations, par exemple modifier le message affiché ou ajouter des commentaires. Quand le groupe aura choisi son projet, mettez à jour ce README pour expliquer son objectif et comment l'utiliser.

Si vous débutez avec GitHub, vous pouvez utiliser **GitHub Desktop** pour récupérer le dépôt, enregistrer vos changements (commit) et les envoyer sur GitHub (push). Demandez à un collègue de vous montrer avant de modifier les mêmes lignes en même temps.
